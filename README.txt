PivotCalc PWA

المحتويات:
- index.html: واجهة التطبيق.
- styles.css: ملف CSS محلي بدون CDN.
- app.js: وظائف الحاسبة، التثبيت، اللغة، الوضع الليلي، وروابط التواصل.
- sw.js: Service Worker للتشغيل دون اتصال بعد أول تحميل ناجح.
- manifest.webmanifest: إعدادات PWA والتثبيت.
- icon-192.png / icon-512.png: أيقونات التطبيق.

مهم:
1) فتح index.html مباشرة من الجهاز يعمل كصفحة محلية دون إنترنت، لكن Service Worker وميزة تثبيت PWA لا يعملان من file:// في المتصفحات الحديثة.
2) للحصول على التثبيت الرسمي والعمل كـPWA: ارفع الملفات على HTTPS (أو اختبر عبر localhost). بعد أول تحميل ناجح وتسجيل Service Worker يمكن للتطبيق العمل دون اتصال.
3) روابط Telegram وWhatsApp وLinkedIn وFacebook وX والبريد تستخدم روابط رسمية/معتمدة من الخدمة؛ النظام يحاول فتح التطبيق إذا كان مثبتاً، وإلا يفتح الويب حيث تدعم المنصة ذلك.
4) لا توجد إعلانات أو مكتبات خارجية أو CDN داخل حزمة التطبيق.
